# Проверка содержания 15.10.0

Проверены 10 учебных карточек и 8 соответствующих ответов банка. Это адресная проверка найденных неточностей, а не утверждение о проверке всего корпуса.

| Карточка / банк | Уточнение | Первичный источник |
| --- | --- | --- |
| 1000020 | Ключ хоста нужно подтвердить через доверенный канал; ssh-keyscan не подтверждает подлинность | [OpenSSH](https://man.openbsd.org/ssh-keyscan) |
| 1000986 | Средняя нагрузка включает R и D и не равна загрузке CPU | [Linux man-pages](https://linuxman7.org/linux/man-pages/man5/proc_loadavg.5.html) |
| 1002082 / qb_nx_004 | IXFR допускает UDP, если ответ помещается в один пакет | [RFC 1995](https://www.rfc-editor.org/rfc/rfc1995) |
| 1000292 / qb_cld_002 | Локальный маршрут не имеет безусловного приоритета; его цель допускает замену | [AWS: таблицы](https://docs.aws.amazon.com/vpc/latest/userguide/subnet-route-tables.html), [замена цели](https://docs.aws.amazon.com/vpc/latest/userguide/replace-local-route-target.html) |
| 1001573 / qb_obs_001 | SLO часто строже SLA, но это не часть определения | [Google SRE](https://sre.google/sre-book/service-level-objectives/) |
| 1001574 / qb_obs_005 | Сбросы счётчиков, классические/нативные гистограммы, невозможность усреднять квантили | [Типы метрик](https://prometheus.io/docs/concepts/metric_types/), [гистограммы и сводки](https://prometheus.io/docs/practices/histograms/) |
| 1001585 / qb_obs_004 | Pull не исключает перегрузку; Pushgateway требует управления жизненным циклом метрик | [Prometheus](https://prometheus.io/docs/practices/pushing/) |
| 1001594 / qb_obs_002 | Бюджет по запросам нельзя автоматически переводить в минуты | [Google SRE Workbook](https://sre.google/workbook/implementing-slos/) |
| 1001595 / qb_obs_008 | Число рядов определяется наблюдаемыми сочетаниями, произведение даёт верхнюю оценку | [Модель данных Prometheus](https://prometheus.io/docs/concepts/data_model/) |
| 1002389 / qb_ntr_007 | Динамический SNAT отличается от явного DNAT для входящих соединений | [Netfilter NAT HOWTO](https://www.netfilter.org/documentation/HOWTO/NAT-HOWTO-6.html) |

В этих записях добавлен редакторский краткий ответ. Остальные длинные ответы показывают начальные законченные предложения, если можно безопасно выделить границу; полный текст доступен через «Подробнее». Код и технические литералы не сокращаются посередине.

90 заданий с шаблоном «какие дополнительные диагностические данные» отмечены `practice: true` и показаны отдельным набором. Идентификаторы и ключи прогресса не изменены; 3015 обычных + 90 практических + 329 карточек из видео = 3434.

Команды банка сохранены. В восьми соответствующих карточках команды синхронизированы с банком; это также восстанавливает литерал регулярного выражения `5..` в примере qb_obs_001, где в карточке ранее было `5.`.
