# Changelog

## v14.1.0 (2026-08-04)

Разбор инцидентов переведён в формат, близкий к реальной работе: фаза даёт
исходные данные, вывод делает человек.

### Инциденты: 3 → 8
- Новые сценарии: кеш DNS и TTL при переносе адреса (Сети), OOM-kill по коду 137 (Docker), шторм алертов, скрывший аварию (Monitoring), место держит удалённый файл (Linux), секрет в логе сборки (CI/CD)
- Каждая фаза показывает, что известно на момент решения (`signals`), вывод команды (`evidence`) и влияние на пользователей (`impact`)
- Подсказка (`hint`) лежит в свёрнутом блоке: помогает, если человек застрял, но не попадается на глаза до попытки
- Раньше вопрос содержал готовый диагноз («вы выяснили, что поды стартуют 25 секунд») — оставалось выбрать вывод. Теперь диагноз ставится по данным

### Исправлено: сценарии проходились без знания темы
- Во всех 12 фазах правильным был второй вариант, а порядок не перемешивался — стратегия «всегда B» давала 100%. Теперь варианты перемешиваются при каждом показе, а подсветка верного идёт по исходному индексу, а не по позиции на экране
- Во всех 32 фазах верный вариант был самым длинным, то есть длина работала подсказкой. Дистракторы переписаны: ни в одной фазе верный ответ не выделяется длиной, позиции распределены
- Экран итогов больше не опирается на жёсткий список из четырёх фаз: названия берутся из сценария

### Валидатор
Четыре новые проверки `incidents.json`, каждая проверена на намеренно
испорченных данных: верный вариант не может быть самым длинным, варианты
не могут дублироваться, `evidence` обязан содержать команду, `hint` не может
быть пустым.

## v14.0.0 (2026-08-04)

Интерфейс перестроен под понятность: меню сокращено с 22 пунктов до 12 в четырёх
группах, тренажёры собраны на одну страницу, главная отвечает на вопрос «что
делать сейчас», а не показывает список всего, что есть.

### Навигация
- Меню сгруппировано: Учёба / Практика / Прогресс / Справочник
- Названия говорят о содержимом: «Экзамен» → «Вопросы с вариантами», «Собеседование» → «Ответы вслух», «Учёба» → «Учебный план»
- Команды («Копировать прогресс», «Источники», «Проверить оффлайн») вынесены в отдельную группу «Данные» со своим стилем — действие больше не выглядит как раздел
- 11 тренажёров убраны из меню в хаб «Тренажёры»; их прямые ссылки (`#/subnet` и остальные) продолжают работать

### Хаб тренажёров
- Четыре группы по смыслу: Диагностика, Сети, Командная строка, Инфраструктура как код
- Каждая карточка называет навык и форму задания вместо загадочных «Код», «Порты», «Debugging»
- Прогресс и размеры берутся из загруженных датасетов (212 заданий), а не из констант
- Сводный процент и кнопка «Продолжить здесь» с самым близким к завершению тренажёром

### Главная «Сегодня»
- Первый экран — действие: ежедневный блиц и навык дня
- Второй — статус: индекс готовности и уровень
- Готовность по темам свёрнута в раскрывающийся блок и больше не отодвигает действие вниз

### XP, уровни и достижения
- 10 уровней от «Новичка» (0 XP) до «Principal / SRE» (16 000 XP)
- 30 достижений в трёх группах: Теория, Практика, Дисциплина
- XP считается из сохранённого прогресса как проекция, а не отдельным счётчиком: перенос прогресса на другое устройство сразу даёт правильный уровень
- Карточка уровня показывает ближайшую цель — достижение, которое ближе всего к закрытию

### Ежедневный блиц и навык дня
- 5 вопросов в день: 1 Junior, 2 Middle, 2 Senior, по одной теме на слот из ротации по дате
- Набор детерминирован датой: перезагрузка не выдаёт новые вопросы
- Дневной стрик рвётся на пропущенном дне; закрытие дня идемпотентно
- «Навык дня» — одно правило из Best Practices с причиной и конкретным действием, без повторов по кругу

### Индекс готовности
- Один процент 0–100 с весами 35/25/20/10/10 (Теория / Практика / Контрольные / План / Дисциплина)
- Подсказка ведёт туда, где индекс вырастет: «Отвечайте на вопросы по теме "CI/CD" → +7%»
- Следующее действие выбирается по наибольшему запасу составляющей

### Исправления
- Результат диагностического теста никогда не сохранялся: ключ `diagnostic_result` не был объявлен в `DEFAULT_KEYS`, и `storage.js` молча отбрасывал запись
- Сервер отдавал 403 на новые модули: список `publicFiles` в `server.js` — allowlist, и незарегистрированный файл ронял установку service worker целиком, потому что `SHELL_ASSETS` кешируется атомарным `addAll`
- Пороги оценки блица были зашиты под 20 вопросов (`s>=18` для «отлично») и недостижимы для блица из 5 — переведены в доли
- Состояние блица и достижений включено в экспорт прогресса: перенос больше не сбрасывает стрик и не зажигает заново отметки о новых достижениях

### Тесты
- 355 модульных (+117): геймификация 23, блиц 27, их UI 34, тренажёры 21, индекс готовности 12
- 53 браузерных, включая обновлённый тест главной под новую разметку
